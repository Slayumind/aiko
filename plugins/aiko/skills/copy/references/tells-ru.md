# Tells of AI-written Russian

Clusters, not single words. The strongest tell is not a word at all: an impersonal text with no stance,
no example and no number. Most Russian tells are old канцелярит that models amplify, plus English
calques.

**Not tells — never "fix" them:** «ёлочки», the em dash where grammar wants it, ё, correct commas.
Editors now complain that professional typography is taken for a model. Keep it.

## Words
- Didactic links: «важно отметить», «стоит учесть», «следует подчеркнуть» → delete, say the point.
- Inflated role: «играет ключевую роль», «оставил неизгладимый след» → «без кеша страница грузится 3 с».
- School clichés: «в современном мире», «на сегодняшний день», «ни для кого не секрет».
- Ad fillers: «широкий спектр», «индивидуальный подход», «уникальный», «инновационный», «идеальное решение»
  → a fact: «доставка за 2–3 дня».
- Empty verbs: «является», «представляет собой», «осуществляет», «обеспечивает возможность»
  → «Python — язык», «проверяет».
- «Данный» → «этот» or nothing.
- Synonyms instead of a repeat: «Иванов… главный герой… ключевой игрок» → repeat the name or «он».

## Constructions
| Tell | Example | Rewrite |
|---|---|---|
| Не X, а Y | «Это не услуга — это трансформация» | Say only Y |
| Не только…, но и… | «не только быстро, но и удобно» | «быстро и удобно», or one of them |
| Тройки | «ясно, кратко и эффективно» | What is actually true |
| Рубленые фразы | «И вот ты сидишь. Думаешь. Не понимаешь.» | One sentence |
| Мнимый диапазон | «от стартапов до корпораций» | Name the reader |
| Проблема + бодрый финал | «Несмотря на трудности, проект продолжает развиваться» | End on the fact |
| Давайте | «Давайте разберёмся» | Start with the answer |

## Russian-only traps
- **Отглагольные существительные и цепочки родительного падежа:** «осуществление проверки
  соответствия требований» → «проверяем, подходит ли».
- **Страдательный залог:** «язык был разработан» → «Гвидо ван Россум создал Python»; «было принято
  решение» → «мы решили».
- **Деепричастие с чужим подлежащим** (grammar error): «Используя этот метод, результаты
  улучшаются» → «С этим методом результаты лучше».
- **Болезнь «который»:** «метод, который помогает людям, которые пишут» → «метод помогает пишущим».
- **English word order:** subject and verb written out where Russian drops them. The text reads as
  a translation. Read it aloud.
- **Case:** a capital after a colon («Вывод: Текст…») and Title Case headings («Ранняя Жизнь») are wrong
  in Russian.
- **«Вы» with a capital** in text for everyone: it is right only in a personal letter → «вы».
- **Typography:** "лапки" instead of «ёлочек», a hyphen « - » instead of a dash « — », «еще» and «ещё»
  in one text, a comma after «Благодаря этому,» or «Однако,» at the start (rarely needed).
- **Quotes around any metaphor:** «начать с "нуля"» → no quotes.

## Калька с английского

The text was written or thought in English first. Every word is Russian and the sentence is not.
The script catches a few of these (`ru/calque`); the rest you find by reading without the original.

| Tell | Example | Rewrite |
|---|---|---|
| Неодушевлённое «живёт» | «Задачи живут в трекере», «настройки живут в файле» | «ведутся», «хранится» |
| «Дом» для места хранения | «Трекер становится домом задач» | «Задачи переносим в трекер» |
| Вещь «учится» | «Научить счётчик хранить меньше» | «Сократить данные счётчика» |
| Вещь «едет», «уезжает», «доезжает» | «Файлы уезжают на новый сервер» | «переносится» |
| «Побеждает» о правиле | «Побеждает последняя запись» | «Сохраняется последняя запись» |
| Вещь «говорит», «знает» | «Документация говорит, что…» | «В документации сказано, что…» |
| «Не дотягивается», «уживается» | «Скрипт до базы не дотягивается» | «У скрипта нет доступа к базе» |
| Структура оригинала | «**Цель.** … **Готово, когда**» в карточке на десять строк | Две фразы и список |

Not a calque, keep: «код лежит в ветке», «сайт лежит», «вопрос висит», «хвосты». A living verb
that Russian speakers do use about things is fine. The test is the ear, not the dictionary.

Names stay in the original: Blender, Photoshop, Pull Request. A translated name
(«Блендер», «Запрос на слияние») is a calque too, and the reader cannot search for it.

## Chat
«Конечно!», «Безусловно», «Отличный вопрос!», repeating the question, headings in a three-sentence
reply, «Надеюсь, это помогло», «Если остались вопросы — обращайтесь».

## Fixing канцелярит, fast
1. Find the noun made from a verb (-ание, -ение, -ация). Turn it back into a verb.
2. Find who does it. Make them the subject.
3. Cut «является», «данный», «осуществлять», «в целях».
4. Read aloud. If you would not say it at a table, rewrite.
